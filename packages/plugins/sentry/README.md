# @keryxjs/sentry

Sentry error monitoring and distributed tracing plugin for [Keryx](https://keryxjs.com). It captures action exceptions and emits spans for HTTP, WebSocket, and MCP transports, action executions, background tasks, Redis commands, and Postgres queries.

For installation, configuration, and usage, see the docs: **https://keryxjs.com/plugins/sentry**
